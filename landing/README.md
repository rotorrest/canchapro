# Landing Site

Next.js 14 static marketing site for canchapro.com.

## Structure

- **Single page**: `src/app/page.tsx` — all sections (hero, features, sports, pricing, add-ons, FAQ, CTA).
- **Component**: `RotatingHero.tsx` — animated sport name rotation.

## Build and Deploy

```
npm run build
```

Outputs static export to `out/`. Deployed via Cloudflare Pages.
